# Skill Guide

Repository rules and safeguards live in [AGENTS.md](AGENTS.md). Implementation conventions are summarized in [INSTRUCTION.md](INSTRUCTION.md); current project facts are in [CONTEXT.md](CONTEXT.md).

- **Caveman** sets concise, direct communication style for responses.
- **Ponytail** guides implementation toward small, simple changes that preserve security and contracts.
- **Code analysis** applies to read-only reviews. It must not modify files or run database operations.
