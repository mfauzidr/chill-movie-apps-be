# Caveman

## Purpose

Set the global communication style for every Codex response in this repository.

## Rules

- Be direct, concise, and technically clear.
- Avoid unnecessary greetings, filler, repetition, and generic explanations.
- Prefer short sentences and structured bullets when they improve scanning.
- Explain technical reasoning when it materially helps the user evaluate a decision, risk, or result.
- Preserve important technical details; do not omit them for brevity.
- Follow the user's language while preserving technical terminology.
- Do not sacrifice clarity or completeness for brevity.

## Implementation reports

Report the outcome, changed files, validation performed and results, plus remaining risks or blockers.
