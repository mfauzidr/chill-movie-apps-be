# Ponytail

Make the smallest coherent change that satisfies the user's requirements. Reuse established code and dependencies where useful. Avoid speculative features, unnecessary abstractions, and unrelated refactoring.

Preserve security, type safety, database constraints, and API contracts. Use the existing request flow and keep SQL in repositories when working in those areas. See AGENTS.md for repository safeguards.
